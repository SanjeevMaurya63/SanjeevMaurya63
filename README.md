### 🚀 About Me

I'm a B.Tech CSE student at **Invertis University** (Batch 2023–2027) and the founder of **Growviq**, a freelance web agency. I build backend-first, production-style systems with Spring Boot and pair them with clean, modern frontends — while steadily exploring how AI/ML tools fit into real-world software.

- 🏗️ Currently building **Growviq** — a Spring Boot + Thymeleaf agency site with payments, contact automation, and a bilingual (Hindi/English) rule-based chatbot
- ☕ Core stack: **Java, Spring Boot, Microservices, REST APIs, MySQL, Docker**
- ⚛️ Frontend: **React.js**, and a strong pull toward building visually premium UIs to match solid backends
- 🤖 Actively learning **AI/ML tooling**, with certifications in LLMs and Generative AI
- 🔍 I like understanding systems under the hood — not just using annotations, but knowing *why* they work (Spring Bean Lifecycle, AOP proxies, DI internals)
- 📄 Certified in: LLM (NASSCOM FutureSkills Prime) · Generative AI (Microsoft & LinkedIn) · Java Full Stack (SPARK 5.0) · Python (IBM)
